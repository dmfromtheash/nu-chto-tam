# Content Guide

## Prediction Cards

Карточки пишутся как короткие бытовые наблюдения: живо, немного странно, без эзотерического пафоса и без мотивационного плаката. Хорошая карточка держится на одной мысли, конкретной детали и понятном человеческом ритме.

## Длина

- title: 1-4 слова, желательно до 26 символов.
- text: примерно 70-170 символов.
- В карточке не должно быть markdown, списков и длинных абзацев.

## Редкости

- common: простая бытовая подсказка.
- uncommon: более точный образ или лёгкая улыбка.
- rare: хочется сохранить, есть узнаваемый punchline.
- epic: сильная карточка с хорошим попаданием.
- legendary: фирменная фраза сайта.
- mythic: почти не используется, только для самых сильных карточек.

## Anti-AI Filter

Избегать слов и конструкций вроде: вселенная подсказывает, энергия дня, путь трансформации, внутренний свет, открой сердце. Если фраза звучит слишком гладко, её нужно заземлить бытовой деталью: кружка, вкладка, рюкзак, окно, список, кухня, провод.

## Источники Вдохновения

Web research используется только для жанровых принципов: короткость, ясность, вопрос как повод подумать, одна мысль на карточку. Готовые fortune-cookie, horoscope или oracle тексты не копируются.

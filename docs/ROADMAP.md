# Roadmap

## Этап 1: архитектура + БД + сиды

Статус: выполнен.

- Структура проекта.
- Core bootstrap и helper-классы.
- SQLite schema.sql.
- seed.php с 14 casual-паками, 154 карточками, достижениями и настройками.
- Минимальная healthcheck-страница.

## Этап 2: backend + auth

Статус: выполнен.

- Роутинг без фреймворка.
- Регистрация, логин, логаут.
- CSRF для HTML-форм.
- `guest_id` для гостей.
- API: health, packs, auth/me, auth register/login/logout.
- API: open-pack, save-card, history, stats.
- RandomPredictionService.
- Rate limit через таблицу `rate_limits`.

## Этап 3: главная + паки + анимации

Статус: выполнен.

- Рабочая главная страница с карточными паками.
- Загрузка паков через `/api/packs`.
- Открытие случайных карточек через `/api/open-pack`.
- Контекстные поля для question, choice, mood и direction.
- Отображение daily/weekly/monthly как 1/3/5 карточек.
- Rarity UI, loading/error состояния.
- Save-card UX для пользователя и гостя.
- Последние открытия и мини-статистика.
- Reduced motion переключатель.
- Мобильная адаптация.

## Этап 4: кабинет пользователя

Статус: выполнен.

- `/cabinet` для авторизованного пользователя.
- Гостевой экран с приглашением войти или зарегистрироваться.
- Профиль, расширенная статистика и быстрые карточки статистики.
- Сохранённые карточки с поиском, фильтром и сортировкой.
- Заметки к сохранённым карточкам.
- Удаление карточек из коллекции.
- История открытий с фильтрами.
- Смена username и пароля.

## Этап 5: админка

Статус: выполнен.

- `/admin` только для `role = admin`.
- Dashboard с базовой статистикой сайта.
- Управление паками: список, создание, редактирование, toggle active, sort order.
- Управление карточками: список, фильтры, поиск, создание, редактирование, toggle active.
- Пользователи: список, роли, блокировка/разблокировка.
- Защита от потери последнего admin.
- Admin logs для важных действий.
- Лёгкая локальная аналитика посетителей и событий без внешних сервисов.

## Этап 6: полировка + деплой

Статус: выполнен для локального демо.

- Финальная QA-проверка главной, `/open`, кабинета, админки и аналитики.
- Карточки на `/open`: ручное раскрытие, рубашка до клика, нормальная пропорция 5:7, 1/3/5 layout без overlap.
- Мини-статистика разделяет открытые карточки и открытые паки.
- Проверка reduced motion, mobile layout и console errors.
- Helper scripts: `scripts/preflight.php`, `scripts/smoke.php`, `scripts/start-local.ps1`, `scripts/start-tunnel.ps1`.
- Инструкции для локального запуска, Cloudflare Tunnel demo и обычного PHP-хостинга/VPS.
- Финальные security notes и backup-инструкции.

## После первого демо

- Настоящий production hardening.
- Мониторинг ошибок и ротация логов.
- Бэкапы по расписанию.
- Опционально: экспорт статистики, PNG-карточки, достижения в UI.
